Two more worked examples

1. Iron in a CuSO4 bath. 1.00 g of Fe (55.85 g/mol) goes into 100.0 mL of 0.100 M CuSO4. Fe is above Cu, so Fe + Cu2+ → Fe2+ + Cu goes.

n(Fe) = 1.00 / 55.85 = 0.0179 mol; n(Cu2+) = 0.100 × 0.1000 = 0.0100 mol

The ratio is 1 : 1, so Cu2+ runs out first. Cu formed = 0.0100 × 63.55 = 0.635 g; Fe left = 1.00 − 0.0100 × 55.85 = 0.44 g.

2. An oxidation number in a chip material. Tantalum oxide, Ta2O5, is used as a capacitor insulator: 2x + 5(−2) = 0, so Ta is +5. Ta metal (0) is oxidized to +5 when this oxide grows.

Three mistakes to avoid

  1. "Oxidation means adding oxygen." It means losing electrons. Zn → Zn2+ + 2e− has no oxygen.
  2. Leaving electrons in the overall equation. Multiply the half-reactions until the electrons cancel.
  3. "It balances, so it happens." Cu + Zn2+ → Cu2+ + Zn balances but does not go. The order of metals decides.

Practice

Work on paper. The first four repeat the class; the rest go one step further. M in g/mol: Fe 55.85, Cu 63.55, Zn 65.38.

1. In 2 Al + 3 Cu2+ → 2 Al3+ + 3 Cu, which species is oxidized, and which is the oxidizing agent?

AnswerAl is oxidized (0 → +3); Cu2+ is the oxidizing agent.

2. 3 Cu2+ ions receive 4 electrons. What forms, and what is left?

Answer2 Cu; 1 Cu2+ is left. The electrons are limiting.

3. How many moles of electrons deposit 0.0300 mol of Cu?

Answer0.0600 mol: 2 per Cu.

4. Will a Cu wire react with ZnSO4 solution?

AnswerNo: Cu is below Zn in the order of metals.

5. Give the oxidation number of S in SO42−, N in NH3, and Ta in Ta2O5.

Answer+6; −3; +5.

6. Balance Al + Ag+ → Al3+ + Ag. How many electrons move?

AnswerAl + 3 Ag+ → Al3+ + 3 Ag; 3 electrons; charge +3 each side.

7. 1.00 g of Fe goes into 100.0 mL of 0.100 M CuSO4. Find the limiting reactant, the Cu formed and the Fe left.

AnswerCu2+ is limiting (0.0100 against 0.0179 mol); 0.635 g Cu; 0.44 g Fe left.

8. In wet oxidation, Si + 2 H2O → SiO2 + 2 H2. Which element is reduced, and how many electrons move per Si?

AnswerH goes from +1 to 0, so H is reduced; O stays −2. Si goes from 0 to +4, so 4 electrons per Si.
