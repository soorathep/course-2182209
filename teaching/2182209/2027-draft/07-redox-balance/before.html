The question for Class 7 3 min

Class 1 said Cu2+ has 27 electrons, two fewer than Cu. Plating a Cu wire means giving each Cu2+ those two electrons back. Class 7 is about reactions in which electrons pass from one species to another: who loses them, who gains them, and how to make the count balance.

Oxidation and reduction 6 min

Oxidation is loss of electrons. Reduction is gain of electrons.

Dip a zinc strip into blue CuSO4 solution. Copper coats the strip and the blue fades:

Zn → Zn2+ + 2e− (oxidation)
Cu2+ + 2e− → Cu (reduction)
Zn + Cu2+ → Zn2+ + Cu (overall)

The two always happen together: one species can lose electrons only if another takes them. Zn gives the electrons, so it is the reducing agent. Cu2+ takes them, so it is the oxidizing agent. Each line above is a half-reaction.

Oxidation numbers 8 min

An oxidation number is a bookkeeping charge that tracks electrons. Four rules:

  1. An element on its own: 0 (Cu, Si, O2).
  2. A single-atom ion: its charge (Cu2+ is +2).
  3. O is usually −2, H usually +1, Cl usually −1.
  4. The oxidation numbers add up to the charge of the species.

Example. Si in SiO2: x + 2(−2) = 0, so x = +4. Example. S in SO42−: x + 4(−2) = −2, so x = +6.

In oxidation the oxidation number rises; in reduction it falls.

Electrons are counted like atoms 5 min

In the overall equation, electrons lost must equal electrons gained, so the electrons cancel. Al gives 3 electrons and Cu2+ takes 2; the lowest common multiple is 6, so 2 Al react with 3 Cu2+:

2 Al + 3 Cu2+ → 2 Al3+ + 3 Cu

Check: 2 Al and 3 Cu on each side, and charge +6 on each side.

Check yourself 5 min

Write your answers first, then open each one.

1. Is Zn → Zn2+ + 2e− an oxidation or a reduction?

AnswerOxidation: electrons are lost.

2. In Zn + Cu2+ → Zn2+ + Cu, which is the oxidizing agent?

AnswerCu2+: it takes the electrons and is reduced.

3. Oxidation number of Si in SiO2?

Answer+4.

4. Oxidation number of Cu in Cu2O?

Answer2x + (−2) = 0, so +1.

5. How many electrons does one Cu2+ need to become Cu?

Answer2.

6. Balance Zn + Ag+ → Zn2+ + Ag.

AnswerZn + 2 Ag+ → Zn2+ + 2 Ag: 2 electrons, charge +2 each side.
