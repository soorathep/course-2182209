Counting electrons in redox

About 30 minutes. Works in class or on your own, on a laptop or a phone. Nothing to install; a calculator helps.

How this lab works

You decide which species loses electrons when Zn meets Cu2+, assign oxidation numbers, balance a reaction so the electrons cancel, and then treat electrons and ions as reactants that can run out. Write each prediction before you look; the next step stays locked until you do. After two tries the expected value is shown.

What runs where. The expected values come from redox_lab.py, computed in advance. The slider reads values the Python computed. No Python is installed or run on your device. To run the Python yourself, open the slides and press D, or run redox_lab.py in desktop Python.
