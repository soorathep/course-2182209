Overpotential and the limiting current

About 30 minutes. Works in class or on your own, on a laptop or a phone. Nothing to install; a calculator helps.

How this lab works

You calculate how fast a reduction runs at a given overpotential, see how a slow electrode changes that, and then add a limit set by mass transport. Write each prediction before you look; the next step stays locked until you do. After two tries the expected value is shown.

What runs where. The expected values come from kinetics_lab.py, computed in advance. The sliders use the same equations in JavaScript. No Python is installed or run on your device. To run the Python yourself, open the slides and press D, or run kinetics_lab.py in desktop Python.
